# Queen Test Bot

Telegram-бот с тестом и шуточной характеристикой через [RouterAI](https://routerai.ru).
Генерация фото временно отключена: после текста сразу появляется кнопка сообщения
от авторов. Запросы к API вынесены в `routerai_client.py`; метод генерации портрета
сохранён, а его вызов в боте закомментирован.

## Настройка и запуск

1. Установи зависимости: `python -m pip install -r requirements.txt`.
2. Скопируй `config.example.json` в `config.json`, если локального файла ещё нет.
3. Заполни `BOT_TOKEN` токеном Telegram-бота, а `ROUTERAI_API_KEY` — новым ключом
   из [кабинета RouterAI](https://routerai.ru/docs/guides/overview/quickstart).
   Старый ключ OpenRouter для RouterAI не подходит.
4. Пополни баланс RouterAI и запусти `python queen_test_bot.py`.

`config.json` исключён из Git. Вместо файла можно передать настройки через
переменные окружения с теми же именами; они имеют приоритет над файлом.

## Выбор моделей

- `LLM_MODEL`: по умолчанию `x-ai/grok-4.7`. Это стартовый вариант для ручного
  сравнения качества прожарок. По состоянию на 1 ноября 2026 года прежние
  `grok-4-fast` и `grok-4.1-fast` отмечены в каталоге RouterAI как недоступные.
- `TEXT2IMG_MODEL`: по умолчанию `openai/gpt-5-image`.
  Пока фото отключены, эта модель не вызывается и расходы на неё отсутствуют.
  В сохранённом методе для портретов используется RouterAI `/api/v1/chat/completions`,
  поэтому выбирай модель с поддержкой генерации изображений в чате.
  На ручной проверке GPT-5 Image вернула картинку в
  `choices[0].message.images[].image_url.url`; запрос через `/api/v1/images`
  вернул ошибку провайдера HTTP 404 внутри ответа HTTP 200.

Чтобы попробовать другую модель, поменяй идентификатор в `config.json` и
перезапусти бота. Модели не переключаются автоматически.

Документация: [Grok 4.7](https://routerai.ru/models/x-ai/grok-4.7),
[Grok 4 Fast](https://routerai.ru/models/x-ai/grok-4-fast),
[Grok 4.1 Fast](https://routerai.ru/models/x-ai/grok-4.1-fast),
[GPT-5 Image](https://routerai.ru/models/openai/gpt-5-image),
[генерация изображений](https://routerai.ru/docs/guides/overview/multimodal/image-generation).

Ручная проверка API 1 ноября 2026 года: Grok 4.7 выдала добровольную прожарку
с отдельным промптом, а GPT-5 Image сгенерировала нейтральный портрет через
`chat/completions`. Полные ответы сохранены локально в `logs/manual-routerai-*`.
Telegram-бот при проверке не запускался. Исходный промпт прожарки не менялся;
ранее модель отказалась выполнять его требование унизить человека до отчаяния.

Ответы API декодируются из исходных байтов как UTF-8. Исходный `report` передаётся
без изменений; модель получает вопросы, варианты и выбранные ответы.
